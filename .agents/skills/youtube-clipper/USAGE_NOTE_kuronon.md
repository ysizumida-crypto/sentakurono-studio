# くろのんチャンネルでの使い方(必読)

このスキルは外部から導入したもの(op7418/youtube-clipper-skill)。2026-08-04 に社長の指示で追加。

## 何をするスキルか

YouTube の動画をダウンロードし、字幕を解析して章に分け、選んだ区間を切り抜いて、
二言語字幕を焼き込み、要約文まで作る。中国語で書かれている。

## このチャンネルでの用途は「自分の本編の切り抜き」に限る

**他人の動画を切り抜いて投稿してはいけない。** 著作権侵害になる。
このチャンネルでは、本編(A-1〜)から毎日のショートを作る用途にのみ使う。

素材の出どころが自分のものであることを、使うたびに確認すること。

## 導入時に確認したこと

- 外部への送信なし。`subprocess` は ffmpeg と yt-dlp の呼び出しのみ
- 参照先ドメインは youtube / ffmpeg・python の公式ドキュメント / GitHub のバッジ画像だけ
- `rm -rf` は同梱の `install_as_skill.sh` 内にあるが、自身の導入先ディレクトリに限定。
  npx で導入済みのため、このスクリプトを実行する必要はない

## 既存の仕組みとの関係

窓・祝詞・音の設計は `personal_brand/videos/engine/` の自前エンジンが正本。
このスキルはあくまで「完成した本編を切り出す」後工程として使う。
切り抜きに那智の滝の窓を足したい場合は、自前エンジン側で作り直したほうが早い。
