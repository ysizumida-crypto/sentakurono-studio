# /kuronon-episode — エピソード制作フルパッケージ

## 発動時の入力

- エピソード番号・テーマ(例: A-2 案件の探し方)
- 特記事項(扱ってよい実体験の範囲・NG事項)

## 出力先

`personal_brand/videos/a{NN}_{slug}/script_v0.1.md`(A-1 のパッケージ構成に準拠)

## 制作規格(=世界を唸らせるための品質バー)

### 構成の型(A-1 で確立・全話共通)

1. **冒頭フック30秒**: 疑問形 or 断言で視聴者の前提を壊す(例:「会社は、買える。」)。尺の2%で勝負が決まる
2. 本編: 12-15分・6〜7セクション。**1セクション=1メッセージ**。抽象論の直後に必ず具体(数字・実体験の一般化)を置く
3. **§終盤に「正直な話」枠**: 失敗・不安・限界をひとつ開示(authenticity =2026年世界トレンドの核)
4. **開運チャームコーナー**(毎回世界の縁起物1つ・ローテ管理: 四つ葉→馬蹄→てんとう虫→招き猫→風水コイン→ダーラナホース→ハムサ→ナザール…)
5. **締めの口上(固定)**: 日「あなたの運気が、今日も一羽ぶん、上向きますように。」/ 英 "May the sun crow guide your fortune today."

### ナレーション文体(VOICEVOX 青山龍星用)

- 一文は短く。読点で息継ぎを設計。漢数字・誤読しやすい語はひらがな表記
- 一人称「僕」・語りかけ体。専門用語は初出時に一言定義
- 表情指定を段落単位で付す: normal / happy / surprised / troubled / serious(production素材と一致)

### ビジュアル規格

- サムネ: 日本語メイン(墨系太字)+英語キーフレーズ(小)・くろのん右側配置・**右肩上がり対角線**・日輪 #F5C542・背景 #FBF3E4
- 画面素材: 開運デザイン体系 v2.0(`personal_brand/strategy/avatar_character_design.md`)のシンボル辞書から選定
- キャラ素材: `personal_brand/videos/avatar/production/`(表情4種+口パク2種+ベース)

### メタデータ規格

- タイトル: 日英各3案(英語は言語別メタデータ用)。「儲かる」系の煽り禁止(広告主フレンドリー維持)
- 概要欄: A-1 の固定文言を継承(八咫烏説明・専門家確認ディスクレーマー・守秘方針・VOICEVOX:青山龍星クレジット・AI音声明記・英文パラグラフ)
- 投稿時間: JST 19-21時(米東部朝・英国昼を同時に取る)

## コンプライアンス・チェックリスト(全話・公開前に必ず消込)

- [ ] 旧勤務先の商号・役職・在職情報・業務上知り得た情報ゼロ(**退職後も守秘義務は存続**)
- [ ] 案件特定情報ゼロ(屋号・所在地・金額・仲介名・案件No.・プラットフォーム由来情報)— BATONZ NDA等は案件消滅後も存続
- [ ] 破談・実体験は一般化表現のみ(新規の言及範囲は壬生確認)
- [ ] 法務・会計・税務の解説に「専門家に確認した一般論」ディスクレーマー(動画内テロップ+概要欄)
- [ ] 開運演出をサロン・特定商品/役務と結びつけていない(景表法)
- [ ] 自社事業の紹介を含む回: 有料プロモーション設定ON+広告明示テロップ
- [ ] AI生成コンテンツ開示ラベルON・VOICEVOXクレジット記載

## 制作手順(社長の実働は約2時間/本)

1. `/kuronon-episode` で台本パッケージ生成(組織・無料)→ 社長レビュー
2. VOICEVOX で音声生成(青山龍星・台本を章ごとに貼付・話速0.95推奨)
3. CapCut で組立て: くろのん素材+口パク循環(閉→半開→開)+画面素材+テロップ
4. サムネ制作(仕様書どおり・Canva可)
5. コンプラチェックリスト消込 → 公開予約(JST 19-21時)
6. 公開後: `personal_brand/upload/` パイプラインでSNS横展開(鳳)
