# youtube-format-check — 形式変更の損得を検証する

「この作り方の方が有利では?」という問いは、答えが**面によって正反対になる**。同じ「静止画+音」が、ショートでは自殺行為で、環境音ジャンルでは標準形になる。だから最初にやることは答えを出すことではなく、**どの面の話かを確定させること**。

## 手順

### 1. どの面の話かを確定する

| 面 | 視聴のされ方 | 評価軸 |
|---|---|---|
| **ショート** | スワイプ送り。次が無限にある | 最初の1〜1.5秒で切られるかどうか。視聴維持率 |
| **本編(語り)** | 検索・関連から能動的に選ぶ | 総視聴時間。中盤の離脱 |
| **環境音・作業用** | 再生して**画面を見ない** | 1再生あたりの長さ。回遊性 |

面が違えば、同じ変更が真逆に効く。ユーザーが面を明示していなければ、勝手に決めずに確認する。

### 2. その面の評価軸に照らす

**ショート**では、視聴者は内容を理解する前に指が動く。動きのない画は「まだ何も始まっていない」と読まれて即スワイプされる。静止画は維持率を直接削るので、**ショートで静止画化は原則として損**。

**環境音**は逆で、視聴者は画面を見ていない。動きは価値を生まない。ただし後述の規約リスクが本体になる。

**本編**は中間。語りが主役なので、背景の動きは大きな要因ではない。

### 3. 収益化規約に当てはめる

2025年7月、YouTube は「再利用コンテンツ」を「**本物でないコンテンツ**」に改称し、**大量生産・テンプレート的な動画は収益化対象外**であることを明確にした。1本ずつは自作でも、量産できる形なら該当する。

静止画+長時間の音は、まさにこの形をしている。判定される側に回りやすい。**形式変更が規約リスクを新しく作らないか**を必ず見る。

回避の鍵は**差別化できる自分の資産があるか**:

- 自分で撮った実写がある → 強い。テンプレートではない
- 各動画で映像が明確に違う → 強い
- 素材を使い回し、文字だけ差し替え → 弱い。危険

### 4. 数値は必ず検索で裏を取る

アルゴリズムの数値は変わる。さらに、世に出回っている「維持率◯%が基準」という数字の**ほとんどは YouTube の公表値ではなく、SEO 業者の推定**である。答えるときは、

- 検索して現在の情報を確認する
- 公表値と推定値を区別して伝える(「◯%と言われています」と「YouTube が公表しています」は違う)
- 出典を示す

推定値を断定として伝えると、社長は数字を根拠に投資判断をしてしまう。そこは正確に。

### 5. 折衷案を探す

「変える / 変えない」の二択で答えない。多くの場合、**両方の利点を取る第三の案**がある。

例: 環境音市場を狙いたいが静止画は規約リスク → 自分で撮った実写を固定して流す。動きがあるので維持率も規約も安全で、環境音の需要にも応えられる。

## 答え方

結論を先に、理由を後に。以下の順で書く。

1. **結論**(面ごとに分けて。「ショートでは損、環境音としてなら有り」のように)
2. **なぜそうなるか**(視聴のされ方から説明する。アルゴリズムを擬人化しない)
3. **規約リスク**(あれば必ず。見落とすと収益化が丸ごと飛ぶ)
4. **推奨する第三の案**(あれば)
5. **検証の仕方**(実際に試して測る方法。1本試すだけで分かることは多い)

数字を出すときは出典を添える。「調べた結果」と言うだけで根拠を示さないのは、調べていないのと同じ。

## この判断でやりがちな失敗

- **面を混ぜる**: 「YouTube では静止画は不利」と一般化してしまう。環境音では標準形なので誤り
- **規約を見落とす**: 維持率の話だけして収益化資格の話をしない。後者の方が損害が大きい
- **記憶で答える**: 数値が古い。必ず検索する
- **やらない理由だけ言う**: 社長は市場機会を探している。「不利です」で止めず、その狙いを活かせる形を出す
