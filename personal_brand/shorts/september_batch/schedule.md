# 祈願ショートの型

**貼り付ける文言(タイトル・概要欄・予約時刻)の正本はここにはない。**
`python3 personal_brand/videos/make_upload_guide.py` が生成する `videos/UPLOAD_GUIDE.md` が正本。

以前ここに日別タイトルの表を置いていたが、タイトルに `|` が入るため markdown の表として
読み直したときに縁起物名がすべて落ちた(2026-08-05)。同じ事故を繰り返さないよう表は削除した。

## 規格

- **尺**: 49秒(冒頭2秒は那智の滝の実音ソロ → 祝詞は話速0.82で一句ずつ荘重に奏上)
- **公開時刻**: 各日 15:00 JST(2026-08-05 に 21:00 から変更。社長指示)
  - 時刻は映像に焼き込まれていない(焼き込みは日付だけ)。変更は
    `make_upload_guide.py` の `JST_HOUR` と概要欄の文面を同時に直すこと
- **予約**: YouTube の予約公開に7本ずつまとめて入れる。社長は毎日はアップしない
- AI開示ラベル ON / 子ども向けではない / ハッシュタグはタイトル内 `#Shorts` のみ
- **ファイル名 = 公開日**(`kaiun_MMDD.mp4`)。画面の帯の日付と必ず一致させる

## 祈りローテ(4種循環)

1. あなたの金運の扉が、しずかに、ひらきますように。
2. あなたの努力が、めぐりめぐって、実をむすびますように。
3. あなたのもとに、よいご縁と、よい報せが、とどきますように。
4. あなたの明日が、きょうより、すこし豊かでありますように。

## コンプラ(全本適用)

- 祝詞は略拝詞の正式な形(祓い給え、清め給え、守り給い、幸え給え)
- 「※開運演出はエンターテインメントです」テロップ常時表示・効果保証表現なし・商品/役務との結合なし
- 公開開始は 2026-08-06(社長判断で 2026-09-01 から前倒し。予約投稿で担保)
