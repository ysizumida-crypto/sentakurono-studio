# v2.0 正式アート: 八咫烏「くろのん」開運デザイン体系(2026-08-01)

社長制作の正式アート `../videos/avatar/kuronon_master_art_v2.png` を**マスターアート**として登録。
モチーフを**八咫烏(やたがらす)**——日本神話で太陽に棲み、迷う者を勝利へ導く三本足の神鳥——に昇華。
「見た人の運気が上がる」を世界共通で機能させるため、以下の縁起デザイン体系を規定する。

## 1. 縁起シンボル辞書(画中の全要素に意味を持たせる)

| 要素 | 日本での意味 | 世界への翻訳(発信時に使う説明) |
|---|---|---|
| **三本足** | 八咫烏=天・地・人。迷い人を導く | "The three-legged sun crow guides the lost to victory" — 起業に迷う視聴者を導く記号 |
| **日輪(背後の太陽)** | 天照大神の使い・夜明け | 新しい始まり(new beginnings)。全サムネで頭上に配置し「上昇」を無意識に刷り込む |
| **小判(掲げた金貨)** | 富・商売繁盛 | 風水コイン(中華圏)・lucky penny(米英)と同型の世界共通シンボル |
| **青海波** | 幸運が波のように続く | "waves of fortune" — 無限に続く穏やかな繁栄 |
| **梅** | 春を呼ぶ・忍耐の末に咲く | perseverance blooms — 苦節の末の開花(M&A実録の物語と一致) |
| **富士山** | 一富士=初夢の最上吉兆 | 誰もが知る日本の頂=目標の頂への登頂 |
| **電卓** | 実務・数字に強い | 幸運は計算(準備)する者に訪れる、の記号 |

## 2. 「運気が上がる」機能設計(精神論でなく仕掛けとして)

1. **上昇の構図規則**: サムネ・立ち絵は必ず「右肩上がり」の対角線(翼・小判・視線)で構成。チャート文化圏(全世界の投資層)は右肩上がりに無条件のポジティブ反応を持つ
2. **暖色発光の背景規則**: 背景は日輪の暖色(#F5C542系)+余白。心理的に「明るい・縁起が良い」を言語に依存せず伝える
3. **世界の開運チャーム・エンディング**: 毎話のエンディングで、くろのんが世界の幸運シンボル(四つ葉のクローバー/馬蹄/てんとう虫/招き猫/風水コイン等)を1つ紹介して視聴者に贈る演出。①米英視聴者の自国文化が登場=親近感 ②「最後まで見ると縁起物がもらえる」=視聴維持率向上 ③コメント欄に各国の幸運文化が集まる=国際コミュニティ化
4. **締めの口上(全話固定)**:
   - 日: 「あなたの運気が、今日も一羽ぶん上向きますように。」
   - 英: "May the sun crow guide your fortune today."
5. **概要欄の一文**: 「くろのんは、迷う人を導く三本足の神鳥・八咫烏がモチーフです」の日英併記で、キャラの物語を毎回植える

## 4. 権利・留意事項

- 八咫烏は神話=パブリックドメイン。ただし **JFA(日本サッカー協会)エンブレムの意匠には似せない**(三本足の烏という概念は自由、特定エンブレムの模倣は不可)
- 「運気が上がる」は**エンタメ・縁起物としての表現**に留め、金運保証・スピリチュアル商法的な断定表現(「見れば必ず儲かる」等)は使わない(景表法・プラットフォーム規約対応)
- 神話モチーフの説明は敬意をもって行い、宗教的主張はしない

## 私(=九条)の推奨(選定時の参考・記録)

**案2「くろのん」を主演に、案3のミニマル版をチャンネルロゴに併用。**

理由:
1. 主戦場は日本語圏(収益の土台)。日本での登録者獲得速度は案2が最速
2. 「ゆるいカラス × 1,000万円の買収実録」のギャップが企画の記憶点になる
3. 案3をロゴに使えば英語圏向けのブランド体裁も両立できる
4. 表情記号が多い案2は編集工数が最も軽く、本業侵食ゼロ設計に合う
