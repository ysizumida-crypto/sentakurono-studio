# 音声の欠落を防ぐ規約

2026-08-03、特別編「さようなら」で**10カット中5カットのナレーションが末尾で切れて**納品された。最大 2.97 秒、文の途中で消えていた。

## 何が起きたか

`build_sayonara.py` はカットの尺を台本どおりの固定値で持っていた。

```python
CUTS = [('hook', 10.0, ...), ('world', 16.0, ...), ...]   # ← 固定値
...
audio.append(chunk[:ns*sw] + ...)                          # ← 尺を超えた分を切り捨てる
```

VOICEVOX の合成音声は、台本を書いたときの想定より長くなる。`hook` は 10.0 秒の枠に対し実際は 12.04 秒必要で、はみ出した 2.04 秒が無言で捨てられていた。**エラーは出ない**。切り捨ては仕様どおりの動作だったため、生成は成功扱いで完了する。

| カット | 固定尺 | 必要 | 不足 |
|---|---|---|---|
| hook | 10.0 | 12.04 | -2.04 |
| world | 16.0 | 17.49 | -1.49 |
| origin | 13.0 | 15.66 | -2.66 |
| kakugo | 16.0 | 18.97 | -2.97 |
| gouse | 14.0 | 14.07 | -0.07 |

## 規約

**カットの尺は音声の実長から決める。台本の想定尺を実尺として使わない。**

```python
dur = voff + 音声の長さ + 余韻(0.9秒 / 最終カットは 2.0秒)
```

そのうえで、切り捨てが起きたら必ず止まるようにする。

```python
assert len(chunk) <= ns*sw, f'{key}: 音声が尺を超えています'
```

尺が可変になるため、**効果音は「何秒目」ではなくカット番号に紐づける**。固定秒で置くと、尺が変わった瞬間に鈴や鐘が無関係な場所で鳴る。

```python
SFX_AT = {0:('tuner',0.4), 2:('suzu',0.2), ...}   # カット頭からの相対位置
t0 = STARTS[cut_index] + offset
```

## 納品前の検査

各カットの境界直前 0.4 秒の音量を測る。語りの途中で切れていれば、そこに音が残る。

```python
rms = audioop.rms(voice[int((end-0.4)*rate)*sw : int(end*rate)*sw], sw)
# RMS < 300 なら無音 = 正常。それ以上なら語りが途中で切られている
```

本編(`lf_engine.py`)は最初からカット境界を音声の無音位置から求めているため、この不具合はない。ショート(`generator.py`)は固定尺だが、全要素で 1.7 秒以上の余裕があることを確認済み。**台本を書き換えたら、この検査を必ず通すこと。**
