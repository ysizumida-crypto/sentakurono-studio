# くろのん動画 制作手順書(初心者向け・完全版)

**対象**: 動画制作が初めての人。A-1 を例に、台本 → 音声 → 動画 → アップロードまでを、ソフトの操作レベルで説明する。
**所要時間の目安**: 初回は半日。慣れれば1本2時間。

---

## 全体の流れ(5ステップ)

```
①音声を作る(VOICEVOX・30分)
   ↓
②素材を手元に揃える(10分)
   ↓
③動画を組み立てる(CapCut・初回2〜3時間)
   ↓
④書き出す(10分)
   ↓
⑤YouTubeにアップして公開予約(5分)
```

---

## ① 音声を作る(VOICEVOX)

VOICEVOX は無料の音声合成ソフト。台本の文章を貼り付けると、キャラクターの声で読み上げた音声ファイルが作れる。

1. https://voicevox.hiroshiba.jp/ →「ダウンロード」→ お使いの PC(Windows / Mac)版をインストールして起動
2. 初回起動時の利用規約に同意。**クレジット表記が義務**(概要欄に「VOICEVOX:青山龍星」— metadata.yml に記載済みなのでコピペで満たせる)
3. 画面上部のキャラクターアイコンをクリック →「**青山龍星**」を選ぶ(話者番号 13)
4. 画面右側の設定パネルで「**話速 0.95**」に変更(規格。少しゆっくりめが聞き取りやすい)
5. 台本(`a01_why_buying/script_v0.1.md` の「ナレーション全文」)を **セクション1つぶん**(【1 フック】など)コピーして、VOICEVOX のテキスト欄に貼り付ける
   - 台本は「そのまま貼れば正しく読む」ように、読み間違えやすい言葉をひらがなで書いてある。**勝手に漢字に直さないこと**
6. 再生ボタンで試聴。読みがおかしい箇所だけ、その行をクリックしてアクセント・読みを修正
7. メニュー「ファイル」→「**音声書き出し**」→ `a01_sec1.wav` のような名前で保存
8. セクション2〜9も同様に繰り返す(セクションごとにファイルを分けておくと、編集時にズレ調整がラク)

**できあがり**: `a01_sec1.wav` 〜 `a01_sec9.wav` の9ファイル

## ② 素材を手元に揃える

編集用 PC の1つのフォルダ(例: `デスクトップ/a01制作/`)に以下を集める:

| 素材 | 場所 |
|---|---|
| 音声 9ファイル | ①で作ったもの |
| くろのん立ち絵(表情5種+口パク2種) | このリポジトリの `personal_brand/videos/avatar/production/*.png` |
| サムネイル | `personal_brand/videos/thumbnails/a01_thumbnail.png`(完成済み) |
| 台本(構成表を見ながら組む) | `a01_why_buying/script_v0.1.md` |
| BGM・効果音 | CapCut 内蔵の「商用利用可」素材 or YouTube オーディオライブラリ(無料・要ライセンス確認) |

GitHub からのファイルの取り出し方: リポジトリのページでファイルを開き「Download raw file」ボタン(↓アイコン)。フォルダごとなら リポジトリトップ「Code」→「Download ZIP」が簡単。

## ③ 動画を組み立てる(CapCut)

CapCut は無料の動画編集ソフト(PC版推奨: https://www.capcut.com/)。スマホ版でも同じことができる。

### 3-1. プロジェクト作成

1. CapCut を起動 →「新しい動画」
2. 右上の比率設定を「**16:9**」、解像度「**1080p**」にする(横長動画。Shorts ではない)

### 3-2. 音声を並べる

1. ②のフォルダから `a01_sec1.wav`〜`sec9.wav` を画面下のタイムラインへ順にドラッグ
2. セクション間に 0.5秒ほどの「間」をあける(息継ぎ。詰めすぎると聞き苦しい)
3. これで動画の長さが確定する(約14分半)

### 3-3. 背景とくろのんを置く

1. 背景: 「メディア」→「素材」から無地・和風の背景を選ぶか、生成りの単色(#FBF3E4)を敷く
2. `kuronon_base_transparent.png` をタイムラインの音声の上のトラックにドラッグし、**動画の最後まで引き伸ばす**
3. 位置は画面右寄り・下寄せ(サムネと同じ構図)。サイズは画面の 1/3 くらい

### 3-4. 表情を切り替える(台本の構成表どおり)

台本の構成表に「この秒数はこの表情」と書いてある(例: §1 は serious→surprised)。

1. 該当の時間で、くろのんのクリップを「分割」(ハサミのアイコン)
2. 分割した後半のクリップを右クリック →「置き換え」→ 対応する表情 PNG(`kuronon_serious.png` など)を選ぶ
3. これを構成表の表情指定どおりに繰り返す

### 3-5. 口パク(最初は省略OK)

`kuronon_mouth_half.png` と `kuronon_mouth_open.png` を、しゃべっている間だけ「閉→半開→開」の順に 0.15秒ずつ交互に置くと口パクになる。**手間が大きいので、初回は表情切り替えだけで公開してよい**(第2本目以降の改善課題にする)。

### 3-6. テロップ(字幕)

1. 「テキスト」→「自動キャプション」で音声から字幕を自動生成(CapCut の目玉機能。精度高い)
2. 生成後、台本と見比べて誤字を修正
3. 構成表の「画面素材メモ」にあるキーワードテロップ(「会社は、買える。」等)は「テキスト」→「デフォルト」で大きめに追加
4. **必須テロップ2つ**(コンプライアンス):
   - 法務・会計の話をする §では「※専門家に確認した一般論です」を画面下に表示
   - §6 の破談の話では「※特定の案件・企業の情報は含みません」を表示

### 3-7. BGM

1. 「オーディオ」→ CapCut 内蔵の商用利用可 BGM から、和風・落ち着いた曲を選ぶ
2. 音量は **-25dB 前後**(ナレーションの邪魔をしない小ささ)まで下げる

---

## ④ 書き出し

1. 右上「エクスポート」
2. 設定: 解像度 **1080p** / フレームレート 30fps / 形式 **MP4**
3. ファイル名を `final.mp4` にして書き出し

---

## ⑤ YouTube にアップして公開予約

詳細手順は `personal_brand/upload/README.md` の「段階1」参照。要点:

1. https://studio.youtube.com/ →「作成」→「動画をアップロード」→ `final.mp4` をドラッグ
2. タイトル・説明・タグ: `a01_why_buying/metadata.yml` からコピペ
3. サムネイル: `thumbnails/a01_thumbnail.png` をアップ
4. 「改変または合成されたコンテンツ」= **はい**(AI音声のため必須)/「子ども向け」= いいえ
5. 公開設定 →「**スケジュールを設定**」→ **2026年9月1日 19:00**(公開解禁日。それ以前の公開は禁止 — CLAUDE.md)
6. 公開予約の前に、台本末尾のコンプラチェックリストを消し込む(§6 は壬生確認が必要)

## つまずいたときは

- VOICEVOX の読みがおかしい → その文だけ選んで「アクセント」タブで調整。直らなければ台本の該当語をひらがなに変えてよい
- CapCut の操作が分からない → 「CapCut PC版 使い方」で検索すると公式チュートリアル動画がある
- 音ズレ・書き出し失敗 → プロジェクトを保存してソフトを再起動してから再エクスポート

分からない工程があれば、このリポジトリのセッションで「◯◯の工程を詳しく」と聞けば、さらに細かく手順を出します。
