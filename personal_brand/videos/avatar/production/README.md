## 口パクの使い方(CapCut等)

音声に合わせて `base(閉) → mouth_half → mouth_open → mouth_half → …` を循環。
2コマ(閉/開)でも成立するが、3コマの方が滑らか。表情カット中の口パクが必要になったら、該当表情のSVGに口オーバーレイを足して追加生成する。

## 再生成手順(組織内・無料)

```bash
# SVG編集後:
chromium --headless --default-background-color=00000000 \
  --screenshot=<出力>.png --window-size=1254,1254 <対象>.svg
```

## チャンネルのプロフィール写真

| ファイル | 内容 |
|---|---|
| `channel_icon_800.png` | **採用中**。日食(夜地+金のコロナ)・800x800・不透過 |
| `channel_icon_800_sun.png` | 別案。日輪(夜地に平らな金の円) |
| `make_channel_icon.py` | 生成器。`python3 make_channel_icon.py <出力> [eclipse|sun]` |

YouTube はプロフィール写真を**必ず円に切り抜き**、コメント欄では **48px** まで縮める。
そのため全身は使わず、`kuronon_happy.png` の**頭だけ**を切り出している。

配色はサムネイル(`thumbnails/a01_thumbnail_mystic.html`)と同じ夜と金で揃えた。
**くろのんの頭を日食の影に見立て、輪郭のすぐ外を金で光らせる**のが標準。
真っ黒な頭を夜地に置けるのはこのコロナがあるからで、金一色の地より小さくしたときに強い。

- コロナは頭の輪郭からの**距離**で作る。円を描く方式だと寝ぐせのところで光が途切れる
- 金貨は入れない。元絵では頭の右 871px から始まるため、頭を包む円の半径は **250px 未満**に保つ
- ネクタイも入れない。赤が現れるのは元絵の **y=775px** から。円の下端はその手前で止める
- 四隅まで塗った**不透過**で出す。透過のまま渡すと、円に切り抜かない表示で角が黒く落ちる

実測(生成時に自動で出る): 円の外にはみ出した絵 **0px** / 48px に縮めたときの明暗差 **L\* 97.6**。

素材(`kuronon_happy.png`)を差し替えたら、生成器の冒頭にある実測値(頭の円・寝ぐせの位置)を測り直すこと。
