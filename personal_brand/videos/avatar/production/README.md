`.svg` は同名PNGの生成ソース(ベース画像+表情オーバーレイ)。修正時はSVGを編集して再レンダリングする。

## 口パクの使い方(CapCut等)

音声に合わせて `base(閉) → mouth_half → mouth_open → mouth_half → …` を循環。
2コマ(閉/開)でも成立するが、3コマの方が滑らか。表情カット中の口パクが必要になったら、該当表情のSVGに口オーバーレイを足して追加生成する。

## 再生成手順(組織内・無料)

```bash
# SVG編集後:
chromium --headless --default-background-color=00000000 \
  --screenshot=<出力>.png --window-size=1254,1254 <対象>.svg
```

## 規律

- 新規パターン追加時も `kuronon_<expression>_<mouth>.png` の命名規則に従う
- マスターアートの改変は社長承認後のみ(ブランド正本)

## チャンネルのプロフィール写真

| ファイル | 内容 |
|---|---|
| `channel_icon_800.png` | チャンネルのプロフィール写真(800x800・不透過) |
| `make_channel_icon.py` | その生成器。`python3 make_channel_icon.py channel_icon_800.png 0.70 8` |

YouTube はプロフィール写真を**必ず円に切り抜き**、コメント欄では **48px** まで縮める。
そのため全身は使わず、`kuronon_happy.png` の**頭だけ**を切り出してブランドの金地に置いている。

- 金貨は入れない。元絵では頭の右 871px から始まるため、頭を包む円の半径は **250px 未満**に保つ
- ネクタイも入れない。赤が現れるのは元絵の **y=775px** から。円の下端はその手前で止める
- 四隅まで金で塗った**不透過**で出す。透過のまま渡すと、円に切り抜かない表示で角が黒く落ちる

実測: 頭と地の明度差 L\* **67.7**(コントラスト比 **9.5:1**)/ 円の外にはみ出した絵 **0px**。
48px に縮めても、寝ぐせ・目・くちばし・頬がすべて残ることを目視で確認済み。

素材(`kuronon_happy.png`)を差し替えたら、生成器の冒頭にある実測値(頭の円・寝ぐせの位置)を測り直すこと。
