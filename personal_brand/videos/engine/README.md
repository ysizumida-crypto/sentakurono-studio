# 本編生成エンジン(lf_engine)

横型 1920x1080 の本編動画を、サンドボックス内で全自動生成するエンジンの正本。
ショート版の生成器(`personal_brand/shorts/september_batch/generator.py`)と同じ制作系譜(2026-08-03 確立)。

## 構成

| ファイル | 役割 |
|---|---|
| `lf_engine.py` | 共通エンジン。VOICEVOX合成(冥鳴ひまり)・口パク・瞬き・神域の窓・鈴/チューナーSFX・4系統音声ミックス |
| `build_a01_v4.py` | A-1「なぜ会社を買うのか」v4(32カット・§9開運祈願に神域の窓) |
| `build_a02.py` | A-2「案件はこう探す」(31カット・§9開運祈願を新設) |
| `build_a03.py` | A-3「売り案件情報の読み方」(36カット・§10開運祈願を新設) |

## 制作規格(要点)

- **音声**: VOICEVOX 冥鳴ひまり(speaker 14)・話速 1.15。祝詞のみ 0.82速・句間 1.4・音量 1.08 の三部合成(社長指示 2026-08-02: 略拝詞の正式形「祓い給え、清め給え、守り給い、幸え給え」を、ゆっくり・はっきり)
- **神域の窓**: 那智の滝+飛瀧神社鳥居(社長撮影・バーチャル三脚固定・18.2秒パリンドローム)を楕円マスクで蝕の中心に合成。開運祈願セクションのみ
- **カット割り**: 台本テキストのマーカー位置を無音ギャップ(±2.2秒)にスナップして自動分割
- **音響**: ナレーション+BGM(Ishikari Lore 0.15・深ダック)+那智の滝実音(0.20・浅ダック)+SFX(開始/終了チューナー・チャーム/祈願の鈴)
- **表記**: 「くろの せんたろう」等の個人名は出さない(くろのんのみ・社長指示)

## 実行

```bash
# VOICEVOX エンジン起動後(127.0.0.1:50021)
python3 build_a02.py   # → workdir に a02_master.mp4
```

素材(背景ループ・アバター・滝素材・BGM)のパスは `lf_engine.py` 冒頭の定数を参照。
mp4/wav はリポジトリに含めない(生成物はチャット納品)。
