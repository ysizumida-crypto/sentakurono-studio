# 週次の作業手順(自動起動時の指示書)

毎週日曜の朝、新しい作業場所で目覚めた私が読む手順。社長の承認済み設計(2026-08-04)に基づく。

## 立場の確認

**公開は社長がする。私は作って渡すところまで。** これは便利さの問題ではなく安全の問題で、
2026-08-03 に私の検査を3回すり抜けた不具合(背景24fps)を止めたのは社長の目だった。
数値が全部合格でも、社長には不自然に見えることがある。だから最後の判断は渡さない。

## 手順

### 1. 素材を組み立てる(15〜25分)

```bash
bash personal_brand/videos/engine/bootstrap.sh ~/kuronon-work
```

途中で「固定が基準に達しませんでした」と止まったら、そこで作業を中止して社長に報告する。
不確かな素材で30本作っても意味がない。

### 2. 在庫を確認する

`personal_brand/shorts/inventory.md` に、どこまで納品済みかを記録している。
**常に14日ぶんが社長の手元にある状態**を保つ。足りない日数ぶんだけ作る(通常7本)。

チャンネルURLが記録されていれば、公開フィード
(`https://www.youtube.com/feeds/videos.xml?channel_id=...`)を読んで、
実際に公開されているかを確認する。予定と食い違っていたら在庫の数え方を直す。

### 3. 内容を作る

ショートの中身(縁起物・祈りの言葉)は**自分で書いてよい**。型は
`personal_brand/shorts/september_batch/schedule.md` にある。守ること:

- 既出の縁起物と重複させない(過去分は inventory.md に一覧がある)
- 効果を断定しない。「〜と言われています」の伝聞で書く
- 祝詞は略拝詞の正式な形から変えない
- 社長の事業・案件・勤務先に触れない

**本編の台本は書かない。** 社長との対話でしか作らない。特に A-4「破談」は、
どこまで書いてよいかを判断できるのは社長だけ。

### 4. 生成して検査する

```bash
cd ~/kuronon-work && python3 <生成器> && bash <圧縮>
```

納品前に必ず測る。**数値が揃わなければ出さない。**

| 項目 | 合格の基準 | 測り方 |
|---|---|---|
| 滝のブレ | 平均1px未満 | `measure_shake.py` |
| コマの重複 | 窓の中で0 | 隣接コマの差が中央値の25%未満の数を数える |
| 音の途切れ | 0箇所 | 各カット境界の直前0.4秒が無音(RMS<300)か |
| 窓の色 | 元素材との差が5未満 | **文字のない領域**で比較(文字の上で測ると縁取りを誤検出する) |
| 音量 | -13〜-16 LUFS | `ebur128` |
| 尺 | 49.0±0.2秒 | `ffprobe` |

落ちたら直して再検査。**3回試して駄目なら、測定値と原因を添えて社長に報告する。**
未完成品は送らない。

### 5. 納品する

7本(初回14本)を送り、必ず測定値を添える。**測っていない項目も書く。**

```
9月15日〜21日ぶん できました(7本)

滝のブレ      0.31px(合格)
コマの重複    0本(合格)
音の途切れ    0箇所(合格)
窓の色        元素材との差 2.7(合格)
音量          -14.6 LUFS(合格)

※測っていない項目: 絵の好み、言葉の響き、縁起物の選び方
```

最後の一行を省かない。社長が「そこは自分が見る」と判断できるようにするためにある。
2026-08-03 の不具合は、まさに私が測っていなかった項目だった。

### 6. 記録して、次を予約する

`inventory.md` を更新してコミット・プッシュする。作業場所は消えるので、
**記録に残さなかったことは次週の私には存在しない。**

## 社長が動かれていないとき

平時は日曜の1通のみ。しつこくしない。ただし在庫が減ったら段階的に強める。

| 在庫 | すること |
|---|---|
| 8日以上 | 何も言わない |
| 4〜7日 | 「まだアップされていないようです」と一度だけ |
| **3日以下** | **「あと◯日で配信が止まります」とはっきり伝える** |

毎日鳴らす通知は読まれなくなる。**本当に危ないときだけ大きくする**から、その1通が届く。

## やってはいけないこと

- **YouTubeへ直接アップしない。** 権限を持っていないし、持つべきでもない
- **検査に落ちたものを「たぶん大丈夫」で送らない**
- **本編の台本を勝手に書かない**
- **測っていない項目を、測ったかのように報告しない**
